Honest limits

  • It sees only name and signature errors: about 16% of failing answers on GitChameleon. The other ~84% are logic errors.
  • Gains are small but consistent: +4.2 over plain generation, +2.6 over self-debug (just under the 3-point bar we set), 0 problems broken.
  • One model family on the main benchmark, one invented SDK. The second model confirms the SDK result and is inconclusive on GitChameleon.
  • It guarantees the code is callable on the installed version, not that it means what you intended. Repair prints a diff; writing is opt-in.
  • Where good docs exist they still win (22/24 vs 9/24). PinPoint matters when docs are missing, stale or for the wrong version.
  • The probe imports the target libraries, which runs their import-time code. Use it only on environments you trust.
